# AI Learning Intelligence Library

獨立開發的繁體中文 AI 免費學習圖書館 PoC V0.1。

## 原則
- Codex 負責程式撰寫、測試與維護；GitHub 管理版本。
- 舊 YouTube 分類圖書館保持不變。
- 未經授權不部署正式網站。
- 不提交 API 金鑰、Secrets、個資或未獲授權的教材全文。

## PoC V0.1
- 繁體中文響應式選單式網站。
- AI 基礎入門 → 生成式 AI 入門。
- 五筆合法免費教材、來源連結與教材選取。
- 有來源的 AI 標準版重點摘要與繁體中文 PDF 下載。

## 進度
已建立 GitHub 工程入口；程式與 Codex 執行環境尚待驗證。
